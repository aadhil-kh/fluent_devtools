## 🛠️ What is Fluent DevTools?

Fluent DevTools is a **100% offline** developer utility app for **Windows 10 & 11**, offering **125+ essential tools** in a single, native Fluent-design app. No internet, no sign-up, no tracking; everything runs locally on your device.

### Features at a Glance

| Category | Tools |
|---|---|
| **Data Tools** (100 tools) | Convert & transform JSON (incl. JSONC / JSONL), XML, YAML, CSV, TSV, TOML and TOON : format, minify, validate, escape/unescape, tree & table views, and convert between any of them, plus to HTML, Markdown and Base64. Generate JSON Schema from JSON / YAML and XSD from XML |
| **Code Generators** | JSON & YAML → C#, Java, TypeScript, Dart, Python, PHP, Go, Rust, C++, Swift, Kotlin · cURL → C#, Java, JavaScript, TypeScript, Python, PHP, Ruby, Go, Rust, Swift, Kotlin, Dart |
| **Encoders / Decoders** (11 tools) | Base64 (text & file, encode/decode), URL, HTML entity, Hex/ASCII, JWT Decoder, Backslash Escape |
| **Cryptography** (2 tools) | Hash Generator (MD5, SHA-1, SHA-2, SHA-3, RIPEMD-160 with HMAC support), AES-128/192/256 & ChaCha20 Encrypt/Decrypt (plus legacy 3DES / RC4) |
| **Utilities** (9 tools) | UUID/ULID Generator, Regex Tester, Cron Parser, Diff Viewer, Color Converter (HEX, RGB, HSL, HSV, CMYK), Lorem Ipsum, Text Case Converter, Timestamp Converter, Age Calculator |
| **QR Code** (2 tools) | QR Generator (text, URL, email, SMS, phone, Wi-Fi, geo, calendar event → PNG, SVG, BMP, PDF, ASCII, Base64, EPS) & QR/barcode Reader |
| **Previewers** | HTML & Markdown live preview |

### Why Developers Love It

- 🖥️ **Native Windows** : WinUI 3 with Fluent design, light / dark / system themes
- ✏️ **Monaco everywhere** : the editor that powers VS Code, with syntax highlighting for every format
- 🔍 **Instant search** : searchable tool catalog across every category and conversion
- 📌 **Pin your tools** : pin favourites and jump straight into any tool from the Windows Start menu
- 📤 **Windows integration** : open & save files, copy to clipboard, share output with other apps
- 🛡️ **Zero telemetry** : no analytics, no network calls, no account needed

## 🐛 Filing an Issue

Use the [**Issues**](../../issues) tab to:

- 🐞 **Report a bug** : describe what happened, what you expected, and steps to reproduce
- 💡 **Request a feature** : explain the use case and what problem it solves
- ❓ **Ask a question** : if something in the app isn't clear

### Before You Open an Issue

1. **Search existing issues** to avoid duplicates.
2. **Use the latest version** of the app from the Microsoft Store.
3. **Mention your Windows version** (run `winver` to find it) in bug reports.

### Bug Report Checklist

- [ ] Clear, descriptive title
- [ ] Steps to reproduce the issue
- [ ] Expected vs. actual behaviour
- [ ] Screenshots or screen recordings (if applicable)
- [ ] Windows version (`winver`)
- [ ] App version
